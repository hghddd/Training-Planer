# Training-Planer
## Автор: Ступина Василиса

## Описание

"Training Planner" - это десктопное GUI-приложение, разработанное на Python с использованием библиотеки Tkinter. Оно предназначено для эффективного планирования тренировок. Пользователи могут записывать дату, тип и длительность каждой тренировки. Приложение обеспечивает:

*   **Визуальный интерфейс:** Интуитивно понятная форма для ввода данных и отображение тренировок в виде таблицы.
*   **Верификация ввода:** Автоматическая проверка корректности формата даты (YYYY-MM-DD) и того, что длительность является положительным числом.
*   **Фильтрация:** Возможность отфильтровать список тренировок по дате или типу.
*   **Сохранение данных:** Все записи автоматически сохраняются в файл `trainings.json`, обеспечивая их сохранность между сессиями.
*   **Интеграция с Git:** При добавлении новой тренировки приложение автоматически выполняет команды `git add` и `git commit` (если Git установлен и инициализирован в директории проекта), способствуя версионированию данных.

## Примеры использования

1.  **Запуск приложения:**
    *   Убедитесь, что Python установлен.
    *   Также убедитесь, что Git установлен, если вы хотите использовать функцию версионирования.
    *   Сохраните код как `training_planner.py`.
    *   Откройте терминал в директории с файлом и запустите: `python training_planner.py`

2.  **Добавление новой тренировки:**
    *   В поле "Дата" введите дату в формате YYYY-MM-DD (например, `2023-10-27`).
    *   Выберите "Тип тренировки" из выпадающего списка (например, `Бег`).
    *   Введите "Длительность" в минутах (например, `45`).
    *   Нажмите кнопку "Добавить тренировку".

3.  **Фильтрация тренировок:**
    *   В поле "Фильтр" -> "По дате" введите часть даты или полную дату для поиска.
    *   В поле "Фильтр" -> "По типу" выберите нужный тип тренировки из списка или оставьте "Все".
    *   Таблица автоматически обновится, показывая только соответствующие записи.

4.  **Проверка сохранения:**
    *   После добавления нескольких тренировок закройте приложение.
    *   Откройте файл `trainings.json` в той же директории. Вы увидите список ваших тренировок в формате JSON.
    *   Если Git настроен, просмотрите историю коммитов (`git log`), чтобы увидеть автоматические коммиты.
